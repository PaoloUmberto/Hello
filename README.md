# Paolo Umberto Agliati — portfolio

## Publishing on GitHub Pages
1. Copy the contents of this folder (`index.html`, `docs/`, `.nojekyll`) into the root of https://github.com/PaoloUmberto/me
2. Repo → Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder: `/ (root)`
3. The site appears at https://paoloumberto.github.io/me/ after a minute or two

## Project pages
The three project cards link to pages that are not in this folder yet:
`thesis.html`, `nddl.html`, `imcn.html`, `paper.html`.
Drop files with those names next to `index.html` and the links resolve.
